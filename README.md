# Bomb Timer

A countdown timer for kids: a cartoon bomb chases the clock and explodes when time runs out.

The bomb runs along smooth dashed routes around the clock: circles, triangles, rectangles, mazes and animal outlines. Longer timers chain different shapes, so it is always on a fresh line.

**Play:** https://vivilinca.github.io/bombtimer/

- `bomb-timer.html` — the app (single file, open in any browser)
- `bomb-timer-prd.md` — product requirements
